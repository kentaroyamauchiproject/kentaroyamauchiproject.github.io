Mental Navigation

現在地（Point A）から目的地（Point B）へ。

MINDBEBOPは、生産性を高めるためのものではありません。

今、自分の心がどこで立ち止まっているのかに気づき、その次に向かいたいメンタル状態へ進めるようサポートします。

私たちはこれを Mental Navigation と呼んでいます。

Point A → Point B

Point A は、今のあなたのメンタル状態です。

Point B は、次に向かいたいメンタル状態です。

Recipe や CogniHack は、その間を移動するための道筋になります。

なぜ生産性ではないのか

多くの生産性ツールは、「何を終えたか」を問いかけます。

MINDBEBOPは、「心がどこで立ち止まっているのか」、そして「次にどこへ向かいたいのか」を問いかけます。

Point B は、目標でも、スコアでも、ストリークでも、成果指標でもありません。

集中かもしれません。落ち着きかもしれません。始めることかもしれません。止めることかもしれません。休むことかもしれません。

Point B を決めるのは、あなた自身です。

MINDBEBOP はどのように支えるのか

MINDBEBOP の各ツールは、それぞれ異なる種類のメンタル状態の移動をサポートします。

  • MindFlipOut は、行き詰まった捉え方を少しほぐします。
  • MindShoutOut は、今この瞬間の思考を、自分で選んだ未来の時間へ移します。
  • MindZoneOut は、心への刺激を減らしたいときの静かな空間を作ります。
  • MindBackOut は、外からの誘惑や割り込みから注意を守ります。
  • MindBackyard は、プレッシャーなく過ごせる低刺激な居場所を提供します。
  • MindEntry は、Recipe や CogniHack を通して Point B へ導きます。

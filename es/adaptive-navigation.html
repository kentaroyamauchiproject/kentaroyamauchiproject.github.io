Adaptive Navigation

Sigue avanzando, incluso cuando el camino cambie.

Puede que sepas adónde quieres llegar.

Pero el siguiente paso puede parecer demasiado grande. Puede que la ruta actual deje de ayudarte. Quizá otra herramienta se adapte mejor a ese momento. O puede que el propio destino ya no sea el adecuado.

Adaptive Navigation permite que un recorrido mental cambie mientras ya está en marcha.

Puedes cambiar el siguiente paso, la ruta, la perspectiva, la herramienta o incluso el propio Point B sin tener que descartar todo el recorrido.

Los recorridos reales no siguen rutas fijas

Una secuencia fija supone que la ruta seguirá siendo la adecuada de principio a fin.

Pero los recorridos reales rara vez se desarrollan exactamente según lo previsto.

Puedes dudar. Puedes descubrir que el siguiente paso es demasiado grande. Puedes perder impulso. Puedes descubrir algo que cambie la dirección del recorrido.

Adaptive Navigation considera estos cambios como parte del recorrido, no como un fracaso.

¿Qué es Adaptive Navigation?

Adaptive Navigation te permite ajustar lo que sucede a continuación mientras el recorrido sigue activo.

La herramienta

El tamaño del Point B

El Point B puede hacerse más pequeño o más grande.

El movimiento no tiene por qué avanzar únicamente desde un objetivo pequeño hacia uno más grande. Puede ir en cualquiera de las dos direcciones.

El propio Point B

El destino puede sustituirse, redefinirse, posponerse, ampliarse, reducirse o retomarse más adelante.

El Point B puede ser una hipótesis de trabajo.

El Point B puede cambiar más de una vez

Adaptive Navigation no presupone que cada recorrido tenga un único destino fijo.

El Point B puede hacerse más pequeño, más grande, más concreto, más abstracto o cambiar de dirección. Y después puede volver a cambiar.

Thought Rotation no requiere que sustituyas un pensamiento negativo por uno positivo.

Te permite girar el pensamiento hasta que aparezca otra forma de verlo.

Puedes girarlo una vez. Puedes volver a girarlo. Puede que descubras que el pensamiento original todavía contiene algo útil.

Cuando la ruta deja de ayudar

Adaptive Navigation puede comenzar cuando dices explícitamente:

Estoy atascado.

También puede resultar útil cuando:

  • El siguiente paso parece más grande de lo esperado.
  • La ruta actual ya no encaja.
  • Has retomado el mismo recorrido varias veces.
  • Otro destino empieza a tener más sentido.
  • Llegas a un Point B más pequeño y quieres continuar.
  • Descubres que el Point B original no era lo que necesitabas.

La respuesta no consiste simplemente en esforzarse más.

La respuesta consiste en preguntarse qué necesita cambiar.

Toda la Navigation está completa

Puedes llegar a un destino temporal y después elegir el siguiente Point B.

Encontrar los documentos que faltan puede ser una llegada. Abrir el sistema de presentación puede ser otra llegada. Presentar la declaración puede ser la llegada final.

Cada llegada puede convertirse en el comienzo del siguiente movimiento.

No se trata de forzar el progreso

Adaptive Navigation no existe para hacer que todas las personas completen todas las tareas.

A veces, lo adecuado es hacer el paso más pequeño.

A veces, es elegir una dirección más amplia.

A veces, es hacer una pausa.

A veces, es abandonar la ruta.

A veces, es cambiar el destino.

El objetivo no es obedecer el plan original.

El objetivo es que el recorrido pueda seguir respondiendo a la realidad.

Navigation como hábito

Con el tiempo, Adaptive Navigation puede convertirse en algo más que una función.

Puede convertirse en una forma de responder cuando el movimiento se detiene.

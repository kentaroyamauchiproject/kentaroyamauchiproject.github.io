Par où commencer ?

Un instant. Une petite porte.

MINDBEBOP propose plusieurs outils, mais vous n’avez pas besoin de tous les comprendre dès le départ.

Commencez par ce qui se passe pour vous en ce moment.

Si une pensée revient sans cesse

Utilisez MindFlipOut

  • Ouvrez MindFlipOut
  • Écrivez la pensée qui revient sans cesse
  • Regardez-la une fois sous un autre angle
  • Voyez ce qui se passe

Voir sur l’App Store →

Si vous avez peur d’oublier quelque chose

Utilisez MindShoutOut

  • Ouvrez MindShoutOut
  • Notez une chose dont vous souhaitez vous souvenir
  • Choisissez quand elle doit revenir à votre attention
  • Laissez-la attendre jusque-là

Voir sur l’App Store →

Si votre esprit semble surchargé

Utilisez MindZoneOut

  • Ouvrez MindZoneOut
  • Entrez dans le Zone Mode
  • Passez un moment avec moins de stimulations
  • Restez aussi longtemps que vous le souhaitez

Voir sur l’App Store →

Si vous avez une pensée sans savoir quoi en faire

Utilisez MindBackyard

  • Ouvrez MindBackyard
  • Entrez dans l’Espace de pensée
  • Transformez votre pensée en Thought Block
  • Placez-le quelque part, déplacez-le ou laissez-le simplement tel quel

Voir sur l’App Store →

Si vous savez où vous voulez aller, mais avez du mal à commencer

Utilisez MindEntry

  • Ouvrez MindEntry
  • Choisissez un ensemble de Mental Steps
  • Faites le premier pas
  • Continuez à votre propre rythme

Voir sur l’App Store →

Vous n’avez pas besoin de construire un système. Vous n’avez pas besoin d’organiser toute votre vie. Il vous suffit d’ouvrir la plus petite porte qui pourrait vous être utile.

Commencez là où vous êtes.

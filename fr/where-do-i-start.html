Par où commencer ?

Une pensée. Une petite porte.

MINDBEBOP comprend plusieurs outils, mais vous n’avez pas besoin de tous les comprendre dès le départ.

Commencez simplement par ce qui se passe en ce moment.

Si une pensée tourne en boucle sans s’arrêter

Utilisez MindFlipOut

  • Ouvrez MindFlipOut
  • Écrivez la pensée
  • Faites un Flip
  • Voyez ce qui se passe

Voir sur l’App Store →

Si vous avez peur d’oublier quelque chose

Utilisez MindShoutOut

  • Ouvrez MindShoutOut
  • Écrivez une chose
  • Mettez-la de côté
  • Voyez ce qui se passe

Voir sur l’App Store →

Si votre esprit se sent surchargé

Utilisez MindZoneOut

  • Ouvrez MindZoneOut
  • Entrez en mode Zone
  • Laissez votre attention se calmer
  • Voyez ce qui se passe

Voir sur l’App Store →

Si vous ne savez pas de quoi vous avez besoin

Utilisez MindEntry

  • Ouvrez MindEntry
  • Écrivez ce qui se passe
  • Choisissez un chemin proposé
  • Voyez ce qui se passe

Voir sur l’App Store →

Vous n’avez pas besoin de construire un système. Vous n’avez pas besoin d’organiser votre vie. Vous avez seulement besoin d’ouvrir la plus petite porte utile.

Commencez par une seule pensée.

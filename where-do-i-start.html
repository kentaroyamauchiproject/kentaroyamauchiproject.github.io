Where Do I Start?

One thought. One small door.

MINDBEBOP has several tools, but you do not need to understand all of them first.

Start with what is happening right now.

If a thought won’t stop replaying

Use MindFlipOut

  • Open MindFlipOut
  • Write the thought
  • Flip it once
  • See what happens

If you’re afraid you’ll forget something

Use MindShoutOut

  • Open MindShoutOut
  • Write one thing
  • Set it aside
  • See what happens

Use MindZoneOut

  • Open MindZoneOut

  • Let your attention settle
  • See what happens

  • See what happens
